# Getting help

Start with [README.md](README.md), the [recipes](docs/recipes/) and the
[creator contract](docs/CREATOR-CONTRACT.md). Report reproducible defects through
[Issues](https://github.com/Akilleez-QA/foundation-engine/issues), including the
commit, browser/device, reproduction and expected behavior. Remove private data.
For feature proposals, describe a reusable framework contract and a representative
consumer; creators retain control of their game design.

Issue forms: [bug report](.github/ISSUE_TEMPLATE/bug_report.yml) (problem report with
severity S1 to S4), [engine proposal](.github/ISSUE_TEMPLATE/engine_proposal.yml) (change
request) and [question](.github/ISSUE_TEMPLATE/question.yml). Severity levels are defined
in the [software management plan](docs/plan/software-management-plan.md#9-problem-reporting-and-severity).

Ask a how-to question with the Question issue template. Discussions are not
currently enabled. Follow [SECURITY.md](SECURITY.md) for sensitive reports; do not
include vulnerability details in a public issue. There is no guaranteed support
response time.
