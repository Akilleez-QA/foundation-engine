# kits/concept-explorer

Look at a model from every side and learn its parts: an orbit camera (drag, or the `explorer-orbit` axis), `Part` entities (label key, layer, pick radius) that show a pinned label when tapped and fire the world event `part`, layer visibility, a parameter slider, layer toggles and a mini quiz panel (`ui.ts`: real form controls, keyboard and screen-reader reachable). Requires the camera kit. No draws of its own.
