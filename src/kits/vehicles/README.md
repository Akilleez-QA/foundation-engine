# Local vehicle seating

Optional `vehicles()` kit requires `frames()` and `animation()`. It reuses named animation socket rigs and generation-aware coordinate frames. It is a local ownership/follow contract, not a flight simulator or multiplayer vehicle server.

Create a bounded fleet with `createVehicles(frames, maxVehicles = 16, maxRiders = 64)`. Register stable vehicle IDs, frame references, LOD socket definitions and the selected LOD. Seat IDs are socket names validated by the animation rig. `board(rider, vehicle, seat, worldPose)` preserves world pose by computing the socket-relative offset, then commits both seat and rider ownership together. A rider cannot belong to two seats; an occupied seat cannot accept another rider. Unknown sockets/invalid matrices fail before ownership changes. Missing parent frames return false. There is deliberately no implicit teleport into the seat: authors may place the character at a seat approach before boarding.

`pose(rider)` samples current parent × socket × offset. Missing/stale frame generations return null while preserving ownership for explicit recovery. `exit(rider, desiredWorldPoseOrNull, canPlace)` validates the target before detaching. Null preserves the current world pose. Invalid exits leave the rider seated; occupied vehicles cannot unregister.

For author scenes, add `VehicleRider({ id })` and `vehicleRiderSystem(fleet)` after vehicle movement. `boardVehicle(ctx, entity, fleet, vehicle, seat)` uses its current Transform; `exitVehicle(ctx, entity, fleet, target, canPlace)` validates representability/placement before releasing ownership and updating Transform. Gate independent movement with `characterSystem({ when: () => !fleet.hasRider(playerId) })` for a single controlled character, or implement equivalent per-entity authority filtering in your movement system. Never run two independent pose writers on a seated actor. On dismount, existing character/camera controllers may need their documented teleport/reset policy applied.

Costs: bounded rider/vehicle records and O(riders × frame-depth) pose updates; no own draws, inputs, timers, persistence or network traffic. Placement callback should use canonical terrain/collision availability and must be side-effect-free. Collision hulls, seat approach navigation, occupant relocation on destroyed vehicles, transport authority and shared multiplayer ownership are outside this implementation.
