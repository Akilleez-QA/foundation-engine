# kits/chalkboard

A chalkboard drawn as one SVG in the scene overlay: text and labels (translated keys), lines, arrows, circles, rectangles, axes, number lines and free paths. Strokes draw on (stroke-dash, instant under reduced motion), items reveal, hide and spotlight, and a caption line shows who speaks. DOM only: no draw calls, no texture uploads, and the DOM changes only when an item's state changes. Accessible: the board is an image with a title and a description of what is written; captions are a polite live region. The learn kit's timeline drives it.
