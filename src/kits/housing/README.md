# Housing

Separate enter/decorate/store/manage capabilities are checked at mutation. Placement uses an explicit revision, finite axis-aligned footprint, bounded grid support/exclusion samples and overlap rejection. A sample callback cannot reenter to change authority unnoticed: publication rechecks revision and permission. The support test is a configurable sampling approximation, not a complete volume/collision test; restrict content to the supported footprint scale or provide a stricter adapter.

Occupied structures cannot be packed. Packing preserves the complete manifest for recovery rather than deleting contents. Relocate occupants and settle pending external claims before packing; those systems are not silently bypassed. The snapshot is a single local authority envelope. This does not implement interior geometry, portal rendering, server ACLs, arbitrary rotated structures or financial ownership transfers.
