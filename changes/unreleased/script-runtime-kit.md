- **Optional sandboxed scripts (`@kits/scripting`, SCRIPT-01):** Lua 5.4 text loaded at run time, each script in its own capped state, reaching the game only through host functions the creator grants by name, with deterministic, uncatchable per-call instruction budgets, a wall-time stop, fixed-tick timers, a seeded saveable random stream, JSON save/restore, atomic hot reload and per-script faulting. Adds one exact-pinned runtime dependency, `wasmoon` 1.16.0 (MIT), loaded only when a game calls `loadScriptVm`. See [ADR 0120](docs/adr/0120-optional-sandboxed-script-runtime.md) and the [guide](docs/guides/scripting.md).
