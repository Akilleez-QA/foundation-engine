- **Legacy format decoders.** In `npm run convert`: game archives (LZSS or zlib members), palette sprite frame sets, planar LZ77 screens, console TIM textures and ADPCM/VAG sound, multimedia-movie bitmap cast members and Cinepak QuickTime frames, to PNG or WAV with sidecar metadata and provenance receipts. Bounded by declared sizes and fuzzed. See [ADR 0136](docs/adr/0136-legacy-format-decoders.md).
