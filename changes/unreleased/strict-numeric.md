- **Optional strict numeric modes.** Strict numeric modes (`@kits/numeric`): fixed-point words up to 32 bits in a number or 128 bits in a bigint with chosen rounding and overflow, binary-angle sin/cos/atan2 built from `dmath`, and strict reduced-precision float (`f32`, `pc24`). Golden vectors are checked in Node and the test Chromium. See [ADR 0099](docs/adr/0099-strict-numeric-modes.md).
