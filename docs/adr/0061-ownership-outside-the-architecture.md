# ADR 0061: Ownership and authorship are outside the architecture

- **Status:** Accepted
- **Date:** 2026-09-28
- **Area:** Process

## Context

Rules that depend on who writes the code (a person, a team, a model) break when the author changes.

## Decision

- No clause, budget, type or drawing depends on who or which model writes the code.
- An existing area adopts shared systems through behaviour-preserving steps, not ownership exceptions.

## Consequences

- STD-GOV-18.
