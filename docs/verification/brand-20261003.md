# Brand rendering check, 2026-10-03

Scope: documentation art only (`assets/brand/`, README, docs headers); no runtime change.

- Assets are generated by `scripts/brand/build.mjs`; every PNG is rendered by resvg at a whole-number scale and
  rejected if any pixel is outside the eight-colour palette. `scripts/brand/build.test.mjs` checks contrast, palette,
  symmetry, pixel-exact rendering and the committed ASCII art.
- Markdown was rendered by GitHub's markdown API (`gh api markdown`, GFM), then shown with a local approximation of
  GitHub's README styles in a muted headless Chromium. This is not a capture of github.com itself.
- [`brand-20261003/`](brand-20261003/): the README hero at 1012 px (830 px content column) and on a 375 px phone
  viewport at 2x, with `prefers-color-scheme` light and dark; [`lookalike.txt`](brand-20261003/lookalike.txt): the
  silhouette lookalike sanity check (not a trademark search).
- `assets/brand/social-preview.png` was inspected at 1280 x 640.
- Not checked: github.com's own rendering, the uploaded social preview as shown by link unfurlers, physical devices
  and screen readers.
