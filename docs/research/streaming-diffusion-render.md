# Streaming diffusion rendering of an engine's semantic frames

Research pass: 2026-10-18. Status: study only; nothing adopted, no code copied.

Source studied: StreamRender-H3 (Lu, Ye, Li, Xue, Liu, Han, Xie; NVIDIA, 2026),
[project page](https://nvlabs.github.io/Sana/Sol-Engine/StreamRender-H3/). Code lives in the NVlabs Sana repository
(Apache-2.0, branch `sol-engine`, `models/streamrender_h3`). Weights are on Hugging Face
(`Efficient-Large-Model/StreamRender-H3`) under the **MiniMax H3 Community License**.

## Idea

Keep the game in an ordinary code engine: map, physics, rules and input, all deterministic and authoritative. Have
the engine draw each frame as a flat semantic image, one colour per object class with no lighting or texture. A
video diffusion model then turns that stream into photorealistic video in near real time. The demo engine is a
browser racing game written in three.js.

## Mechanism

- **Interface:** one semantic frame per video frame, at 1344×768 and 24 fps in training. The demo uses 13 classes
  (road, road edge, terrain, grass, vegetation, rock, barrier, building, grandstand, billboard, sky, player car,
  rival cars). There are no depth or instance channels, so all rivals share one colour.
- **Model:** a reference-video-to-video-and-audio diffusion transformer (MiniMax-H3 Ref2VA). It is distilled with
  distribution matching from 16 to 2 denoising steps per streaming chunk. Appearance comes from one reference image
  per session; a structured prompt maps colours to classes. Player input reaches the model only through the
  semantic stream.
- **Temporal consistency:** a permanent attention "sink" of the opening frames, recent-chunk history, a fixed
  position template so late windows resemble early ones, a prefix key/value cache, and resampling forcing, which
  trains the model on its own errors.
- **Cost:**
  - 218 ms per streaming step on 8 GB200 GPUs, down from 799.7 ms.
  - The causal VAE decodes two 720p latent frames in 23.8 ms on one GPU.
  - The full model is resident on each GPU with context parallelism.
  - No live frame rate is stated.
- **Data:** about 10,000 paired 15-second clips from about 5,100 AI-driven races on 39 tracks. First frames were
  restyled by an image model into ten lighting looks, prompts were written by a language model, and targets were
  generated by the base model.
- **Agent loop:** a coding agent iterated a causal VAE decoder against fixed checks (reference match, causality,
  latency, PSNR/LPIPS). That took 36 → 24 layers and about 146 → 32 ms in about three hours; a kernel-tuning loop
  then reached 23.8 ms. The team notes that brightness drift was caught only by watching output, not by averaged
  metrics.
- **Stated limits:** one scenario (third-person racing on the game's own tracks), the full model on 8 data-centre
  GPUs, and no per-instance identity in the semantic map.

## Fit with Foundation

The transferable part is the **engine/renderer split**, which matches Foundation's model: the engine owns the
world state and the renderer is replaceable.

Candidates, not authorised:

1. **Optional semantic render mode** in `@kits/three`. Each mesh carries a creator-assigned class; the mode draws
   flat class colours. Optional instance-ID and depth targets would fix the "rivals share a colour" gap. Output
   goes to an off-screen target or a frame stream at a fixed cadence. Uses: neural renderers, dataset capture for
   training or evaluation, segmentation tests, and debugging.
2. **Paired capture tool:** render the same deterministic replay as semantic frames and normal frames. The replay
   and frame identity owners give exact pairing. It must respect provenance and the licences of any model fed
   with it.
3. **Agent-driven optimisation loops:** their decoder loop, a fixed goal plus objective checks plus human
   viewing, mirrors our gate-and-review practice. The lesson to keep is that averaged metrics missed a visible
   defect.

Out of scope for now: shipping or running a diffusion renderer. It needs multi-GPU data-centre hardware, has no
device path, and the current weights' licence excludes the United States.

## Acceptance a semantic-mode prototype would need

- Class and instance targets are bit-stable across replays.
- Cost per frame is measured beside the normal pipeline.
- A paired capture of one template scene has frame-exact alignment.
- Creator-facing class assignment is documented, with no genre words in core.
