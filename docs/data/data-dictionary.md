## 1. Scope

This dictionary defines the data items the engine's tooling and external interfaces
read, write or exchange: tool parameters, environment variables, command options,
committed data files and configured limits. The author API's own types are defined in
TypeScript under `src/author/` and documented in the [guides](../README.md); they are
not repeated here. Channelization, rate groups, sensor data, telemetry and recorder
formats are N/A: the engine has no hardware or telemetry.

`npm run lint:trace` fails if a field of `schemas/read-only-tools.json` is missing from
§2.

## 2. Read-only tool parameters

Generated by `node scripts/docs/reports.mjs tools` from `schemas/read-only-tools.json`.
Units: none; `exposure` is a linear multiplier and `mask` a 32-bit layer bit set.

| Tool | Direction | Field | Type | Required | Range |
|---|---|---|---|---|---|
| `validate_render_mask` | input | `mask` | integer | yes | >= 0, <= 4294967295 |
| `validate_render_mask` | output | (result) | integer | yes | >= 0, <= 4294967295 |
| `validate_scene_output` | input | `output` | object | no | n/a |
| `validate_scene_output` | input | `output.toneMapping` | string | no | one of `none`, `aces`, `agx`, `neutral` |
| `validate_scene_output` | input | `output.exposure` | number | no | > 0, <= 16 |
| `validate_scene_output` | output | `toneMapping` | string | yes | one of `none`, `aces`, `agx`, `neutral` |
| `validate_scene_output` | output | `exposure` | number | yes | > 0, <= 16 |

Defaults when `output` or a field is omitted: `toneMapping` `none`, `exposure` `1`.
Framing, methods, errors and wire limits are in [ICD §4](../icd/icd-dependencies.md#4-read-only-tool-contract-version-020).

| `CI_EVENT_NAME` | string | set by CI | `scripts/ci-results.mjs` | GitHub event name |

| `GITHUB_EVENT_PATH`, `GITHUB_EVENT_NAME`, `GITHUB_SHA`, `GITHUB_OUTPUT` | GitHub runner values | set by GitHub | `scripts/ci-changes.mjs` | Diff range and output for the path filter |

## 5. Committed data files

| File | Format | Fields | Producer | Provenance |
|---|---|---|---|---|
| `SOURCE-MANIFEST.json` | compact JSON | `schema` (`foundation-engine-source-manifest/1`), `version` (package version), `files` (path to SHA-256 hex, sorted) | `tools/build_manifest.py` | Git-tracked files except itself and `PR_BODY.md` |
| `schemas/read-only-tools.json` | JSON | `schema`, `version`, `tools[]` (`name`, `description`, `inputSchema`, `outputSchema`) | hand-written, reviewed | Mirrors `src/author/render-mask.ts` and `src/author/scene-output.ts` |
| `docs/capabilities.json` | JSON | `$comment`, `features[]` (`id`, `title`, `shipped`, `docs`, `evidence[]`), `engine` (`module`, `values`, `types`), `kits[]` (`name`, `exports`), `knobs[]` (`id`, `readBy`), `templates[]`, `scripts[]` | `npm run capabilities` | Read from the code |
| `changes/unreleased/<name>.md` | Markdown | One bold-titled bullet, at most 24 lines, kebab-case file name | contributors | One per change |
| `lint-baseline/docs-claims.json` | JSON | Allowed claim counts per file and feature | `docs-claims --lower` | Known hits in files being rewritten |
| `src/core/dmath.golden.json` | JSON | Inputs and expected results as hex bit patterns | `npm run dmath:golden -- --write` | Computed by `src/core/dmath.ts`; 1,075 cases at the baseline |
| `src/kits/numeric/numeric.golden.json` | JSON | Fixed-point, binary-angle and reduced-precision vectors | `npm run numeric:golden -- --write` | Computed by `src/kits/numeric` |
| `src/core/save/fixtures/v0.2.0/` | save envelopes and manifest | Bytes written by v0.2.0 | captured at v0.2.0 | Pinned by SHA-256 manifest |
| `scripts/fixtures/compatibility/` | source snapshot and manifest | Retained v0.2.0 arcade template | captured at v0.2.0 | Pinned by SHA-256 manifest |
| `perf/budgets.ts` | TypeScript | Reference budgets per port | maintainers | Changes need a reviewed trailer |

The save envelope format itself is owned by `src/core/save/store.ts` and described in
[ADR 0007](../adr/0007-save-store-sections.md).
