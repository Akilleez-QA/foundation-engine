# Template: mechanics

A guided lab: ride a moving platform, step off, collect and equip a probe, and tag a moving target; then set up and pack a small station. It is the integration example for the frames, vehicles, control, animation, equipment, inventory, market, combat and housing kits, and the one template that loads a `.glb` model. For a first game, `blank`, `arcade` or `explorer` are easier to reshape.

```
npm run new-game -- --template mechanics --id my-game --title "My game"
```

This README stays with the template; your copy lives in `game/` and `GAME.md`. The model, sky images, panel texture and chime live in `game/public/` (copied with the game, and built only with it), generated by the Node scripts in `game/tools/` (build-time tools: they never ship, see [your game's files](../../docs/recipes/your-game-files.md)).

## What is in it

| File | What |
|---|---|
| `game/game.ts` | the game, its kits, and every word |
| `game/lab.ts` | the scene: floor, platform, player, kiosk, the animated beacon model, target, the action panel, and the camera |
| `game/session.ts` | the step-by-step lab logic behind the one action button |
| `game/action.ts` | the continue action |
| `game/beacon.asset.ts` | a model asset: `game/public/models/mechanics/beacon.glb` with its licence and source |
| `game/sky-*.asset.ts` | six texture assets for the cube sky |
| `game/save.ts` | the saved market and bag (one versioned save section) |
| `game/lab.test.ts` | the criteria's tests |

## Controls

- Next step: the button at the bottom, E, or gamepad A.
- Move after stepping off the platform: arrows or WASD, or the left stick.

## First steps

Draws are per rendered frame from `npm run play:snap -- --scene <id>` (software rendering, 1280×800) at 986d06b. Each visible `Shape` is about one draw.

| | |
|---|---|
| Scenes | `lab` (the only scene) |
| Tests | `node --import tsx --test game/lab.test.ts`: 9 tests |
| Playtest | none ([write one](../../docs/recipes/write-a-playtest-script.md)) |
| Draws (budget 10) | `lab`: 7 in the opening view; the probe and the tag beam start hidden and draw only once shown |

**First edit.** In `game/lab.ts`, in the `platform` entity, replace `color: 0x5bc8c0` with `color: 0xe0705b`. You should see a coral platform under the player, and the 9 tests still pass.

**Budget.** The opening view leaves 3 of 10 draws, and the probe and tag beam use some of that later in the lab. `npm run play:snap` measures the opening view only, so after adding something, step through the lab in `npm run play` and run `npm run gate` before you rely on the budget.

## What to change first

1. `game/lab.ts`: the beacon entity shows `Model({ asset, clip })`; swap in your own model with the [model recipe](../../docs/recipes/load-a-model.md).
2. `game/lab.ts`, `view.environment`: light and the cube sky ([camera and lighting](../../docs/recipes/camera-and-lighting.md)).
3. `game/session.ts`: the order of the lab's steps and their messages.

Model and sky URLs are fetched from the site root, so host this build at the root of a domain ([share your build](../../docs/recipes/share-your-build.md)).
